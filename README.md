# স্কুল ম্যানেজমেন্ট ওয়েবসাইট — React সংস্করণ

পূর্ণ বাংলায় স্কুল ম্যানেজমেন্ট ওয়েবসাইট: পাবলিক ল্যান্ডিং পেজ
(হেডার, ছবির স্লাইডশো, শিক্ষক স্লাইডার, প্রধানের বার্তা, নোটিশ বোর্ড,
ফুটার) + ডেমো লগইন + অ্যাডমিন কনসোল।

## গুরুত্বপূর্ণ সীমা

- **লগইন শুধু ডেমো:** অ্যাডমিন / শিক্ষক ও শিক্ষার্থী ট্যাব বেছে
  আইডি ও যেকোনো পাসওয়ার্ড দিলেই কনসোল খোলে। পাসওয়ার্ড যাচাই হয় না,
  এটি কোনো বাস্তব অ্যাকাউন্ট ব্যবস্থা নয়।
- **সাইটে কোনো Supabase / কোড অপশন নেই:** সাইটের ভেতরে কোনো
  Supabase সংযোগ কার্ড/স্ট্যাটাস, Developer Code মডিউল, কোড দেখা,
  কোড কপি বা কোড ডাউনলোডের অপশন নেই।
- **একটাই সিঙ্ক বোতাম:** শুধু সেটিংসের **ডেটা সিঙ্ক** কার্ডে একটি
  **সিঙ্ক করুন** বোতাম আছে। চাপলে অফলাইন / লোকাল-মোড বার্তা দেখায় —
  ডেটা এই ব্রাউজারেই থাকে।
- **ডেটা লোকাল:** ডেটা ব্রাউজার ট্যাবের মেমরিতে থাকে। সেটিংস থেকে
  JSON ব্যাকআপ ডাউনলোড / আপলোড করা যায়, এক ক্লিকে নমুনা তথ্য বসানো
  যায়, আবার সব তথ্য মুছে ফেলা যায়।

## মডিউল

### স্কুল ম্যানেজমেন্ট
- ড্যাশবোর্ড
- শিক্ষার্থী
- শিক্ষক
- শ্রেণি ও বিষয়
- হাজিরা
- পরীক্ষা ও ফলাফল (বাংলাদেশি GPA গ্রেডিং)
- ফি ও বকেয়া
- নোটিশ
- ক্লাস রুটিন
- লাইব্রেরি
- পরিবহন
- ভর্তি আবেদন (অনলাইন ভর্তি; অনুমোদনে শিক্ষার্থী তৈরি হয়)
- সেটিংস (স্কুলের নাম, মূলমন্ত্র, ঠিকানা, প্রধানের বার্তা, সোশ্যাল লিংক, ডেটা সিঙ্ক)

### অফিস ম্যানেজমেন্ট
- অফিস কর্মী
- বিভাগসমূহ
- অফিস হাজিরা
- ছুটি ব্যবস্থাপনা
- বেতন / পেরোল
- অফিসের কাজ
- অফিস খরচ
- নথি ও অফিস নোটিশ

### শিক্ষার্থীর বার্ষিক খরচ
- খরচের ধরন (ভর্তি ফি, ইউনিফর্ম, টিউশন, স্টেশনারি, পরীক্ষা, ক্রীড়া,
  উৎসব, পরিবহন, লাইব্রেরি, ল্যাব/কম্পিউটার, উন্নয়ন ফি ও কাস্টম ধরন)
- প্রতিটি শিক্ষার্থীর খাতভিত্তিক মোট, জমা ও বকেয়া হিসাব

## ফাইল গঠন

    package.json        — dependencies ও scripts
    vite.config.js      — Vite + React plugin
    index.html          — entry HTML (প্রজেক্ট রুটে)
    src/main.jsx        — React entry point
    src/App.jsx         — পুরো অ্যাপ (সব কম্পোনেন্ট)
    src/index.css       — সব স্টাইল
    public/assets/      — ছবি (ঐচ্ছিক): hero-classroom.jpg, classroom-kids.jpg,
                          library.jpg, science-lab.jpg

## লোকালে চালানো

    npm install
    npm run dev

## বিল্ড করা

    npm run build

বিল্ড হলে `dist/` ফোল্ডার তৈরি হয়।

## ডেমো লগইন

কনসোলে ঢুকতে লগইন পপআপে অ্যাডমিন / শিক্ষক বা শিক্ষার্থী ট্যাব বেছে
আইডি ও যেকোনো পাসওয়ার্ড দিন। সুপার অ্যাডমিন আইডি বসানোর বোতামে
ক্লিক করলে সুপার অ্যাডমিন আইডি বসে, আর কনসোলে সুপার অ্যাডমিন চিপ
দেখায়। আবারও মনে রাখবেন: এটি ডেমো লগইন, পাসওয়ার্ড যাচাই হয় না।
